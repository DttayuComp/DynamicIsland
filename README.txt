# Fake Island Settings — Web V2

Это веб-версия, которую можно запустить на Windows без Mac.

## Запуск на Windows
1. Распакуй ZIP.
2. Дважды открой `index.html` в Chrome/Edge.
3. Для теста на ПК всё будет работать.

## На iPhone
Чтобы получить ощущение отдельного приложения:
1. Размести папку на любом статическом хостинге (например GitHub Pages).
2. Открой ссылку в Safari на iPhone.
3. Нажми «Поделиться» → «На экран Домой».
4. Запусти с иконки.

## Что сделано
- максимально близкая структура экрана из предоставленного видео;
- русский интерфейс;
- Dynamic Island сверху;
- цветовые кружки;
- переключатели;
- «Выбрать из галереи»;
- информационный блок;
- предпросмотр;
- кнопка поворота интерфейса на 180°.

Это визуальная имитация. Веб-приложение не меняет системный Dynamic Island iOS.
